# Aplicación de Compra de Productos

Esta aplicación está orientada hacia los clientes finales, proporcionando una experiencia de compra personalizada:

**Módulo de Compras**: Facilita la selección de productos, gestión del carrito de compras y procesamiento de transacciones. Los clientes pueden completar sus compras y obtener comprobantes de pago en formato digital para su descarga.

**Gestión de Perfiles de Mascotas**: Permite a los clientes registrar y administrar información detallada de sus mascotas, incluyendo fotografías, datos de identificación y características específicas. Esta funcionalidad personaliza la experiencia de compra al mostrar productos relevantes según las necesidades particulares de cada mascota.
